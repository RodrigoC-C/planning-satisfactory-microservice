# Microservice of calculate of planning satisfactory

 This service is in change of the calculate the best route and better flow, depend the options of user and machine.


### The microservice is realize whit FastApi

## Comand initialization 
    
Create env

    python -m venv venv

Run env on Windows

    .\venv\Scripts\activate

Run env on Linux/Mac

    source venv/bin/activate

Install requeriment
    
    pip install -r requirements.txt

Run aplication for dev
    
    fastapi dev
